# 高净值直播 PPT 模式（在公募流程上叠加，只覆盖下面写到的地方）

> 适用：大纲标题含「高净值」（如【第28期高净值直播大纲】），或成品要进私募直播库。
> **没写到的一律按主 SKILL.md（公募流程）执行**：读大纲、逐页映射、多期拼页（`copy_slides.py`）、换图表数据（`keynote_tool.py`）、派生数字重算、`ppt-review` 复核、▶ 对齐（`align_triangles.py`）。
> 本模式由汤爱学维护（2026-11-22 建，第27期全流程实测后 2026-11-25 整理）。**所有文件都在 `modes/高净值/` 下，主流程只多了 SKILL.md 开头一段路由，公募直播不受影响。**

## 〇、快速开始（每期照做）
1. 读大纲：飞书文件夹 `IscSfJSjXl1nvIdActdcwwAKnDg` 里「【第NN期高净值直播大纲】…」，以文档开头最新版（V2…）为准；V1 里钉大说删掉的页，后续可能又要求恢复，别丢素材。
2. 底稿：**上一期高净值定稿 .key**（坚果云 `42 每月初高净值直播/` 最新文件夹；第27期起母版、隐藏图表源页都已就位）。拷到本机工作目录 `~/live-ppt-tool/hnwNN_claude输出/`。
3. 逐页映射 → 搬页（第一节 1）→ 换数据（第三节）→ 截图/私募页（第四节）→ 交付前加查（第七节）。
4. 交付走第六节；定稿后归档坚果云、写数据复核文档。

## 一、和公募不同的地方（覆盖项）

### 1. 底稿 = 最近一期高净值成品，不是「引用最多的那期」
- 公募规则是「引用最多的期做底稿」；高净值大纲大量引用公募页，照公募规则会选出公募底稿、套错模板。
- 高净值一律用**最近一期高净值定稿 .key** 做底稿（带高净值母版）。引用的公募/武汉场/私募老期页面，用 `copy_slides.py` 整页搬进来，再换成高净值母版。
- 底稿里大纲用不到的页最后删掉（按安全铁律逐页核对后删）。

### 2. 模板与母版（1920×1080）
| 页型 | 母版名 | 主要文字 |
|---|---|---|
| 封面 | 「空白 拷贝」（橙色渐变+磨砂卡片） | 主标题 SourceHanSansCN-Bold **100**，@272,228，宽 1256，可两行；副标题「高净值客户专享直播课」Bold 70，@277,759 |
| 目录 | 「标题页」 | 「一、…」列表 Bold 60，@121,260，左对齐 |
| 过渡页 | 「标题页」 | 「一、xxx」Bold 90 |
| 内容页 | 「样式2 浅色」（网格底+左上小橙圆） | 页标题 Bold **80**，@122,90，宽约 1680（公募是 90 号 @133,114）；长标题可两行 |
| 页码 | 母版自带 | AlibabaPuHuiTiR 33，@约1821,1008 |

- ⚠️ **内页背景以「网格底+左上小橙圆」为准（用户 2026-11-22 定）**。文档里可能有**多个同名「样式2 浅色」**（老版大橙圆、纯白、小橙圆），只有小橙圆是对的（第27期里是第 22 个）。换母版必须直接写序号 `set base layout of s to slide layout N of d`；存变量、取别页 base layout、`make new slide with properties {base layout:…}` 都会按名字落到第一个同名母版，建完/换完都要再按序号设一遍。先列 `slide layouts` 确认序号，导出页图放大左上角确认。
- 底稿里没有正确母版时：从第25期或第27期 .key 用 `copy_slides.py` 拷 1 页内容页进来，母版跟着进来，换完再删掉那页。
- 搬进来的公募页带公募母版（右上「银行螺丝钉」搜索框、顶部渐变条），**全部换成高净值「样式2 浅色」**；换完立刻 `set body showing of s to false`。
- 公募页标题 90 号、位置偏下，换母版后统一改成 80 号 @122,90；原来标题在右栏的页（如星级收益页）保持原位置。
- 其余样式**照 `rules/样式规范_485定稿实测.md`**：图片和走势图框、卡片框一律 **#FEAD00 / 6 点 / 实线，图片无阴影**；▶ 按意群；气泡两端对齐、居中、尖角不被挡；图上文字 ≥30 号；纵轴整数刻度、**有横向刻度线**（主网格线浅灰），和同一份里其他图一致。

### 3. 高净值内容规则（用户/钉大定）
1. **不出现「组合」字眼**；不加私募费率页。
2. 私募策略名用武汉高净值场定稿叫法：「主动优选私募策略」「指数增强私募策略」；页面上具体产品一律写「**某**主动优选私募策略」「某私募中证500指数增强策略」「某中证全指指数增强私募策略」；泛指写「私募股票基金策略」。
3. **私募策略走势一律模糊**，能看出抗跌/有超额即可，不放具体数值（第四节）。
4. 私募策略页配**扫码引导气泡**：「扫码添加投资顾问，回复「关键词」，完成风险测评，等级匹配即可查看策略走势和数据」+ 二维码；关键词和大纲一致（主动优选=「主动」、指数增强=「指增」、全指指增=「全指」）。
5. 未上线/预热期产品只讲策略、不讲产品要素（费率、认购期、规模等）。
6. 数据口径冲突时以往期直播 PPT 为准；高净值可以保留「定投」说法。
7. 回测/统计类页面沿用往期风险提示小字。
8. 钉大第27期反馈：指数增强部分要保留「某指数增强私募策略走势」（500、1000 两张模糊图 + 「指增」气泡，第27期第22页）；「熊市底部也要避开这些风险（私募跑路、杠杆、衍生品）」这类页不放。
9. 宽基指数举例写法（第27期定）：「如中证全指、沪深300、中证800，以及覆盖各行业的中证A500」。

### 4. 版式硬规则（钉大定，做完逐条自检）
- 并列文字（关键词｜解释卡片、要点列表、目录）**左对齐**；文字多的卡片页参考公募488期第23页：每行「圆角标签｜短语」（如 精选/分散/估值/增强）。
- 气泡直接做成往期气泡样式（复制往期气泡改字），不留「请改成气泡」的备注。
- 总结页：有「总结」标题；每条一个橙色 ▶，和该条序号同一行。
- 需要别人补的（私募产品数据、渠道组引导页、待复核数字）：页面**上方画布外**放一行红字【制作备注】，不压页面内容。

## 三、数据更新
- 指数行情、星级、两融：数据工具箱 `scripts/dbms_api.py`（凭证 `~/.config/dbms/token`）；`index-query` 的 `frequency` 写 `"daily"`，长区间分段取；盘中高低价 `fields:["high","low"]`。
- 两融工具箱常晚一天：Wind EDB `M0075992`（中国:融资融券余额，亿元）与工具箱口径一致，可补最新日。美债10年 Wind EDB `G0000891`。
- 用户说「统一截止到某日」就所有页同一天（两融也不例外）；文字里的日期、派生数字（累计涨跌、最大回撤、年化=天数/365）全部跟着改，`keynote_tool.py` 追加行后 `verify` 确认无缺图。
- 改字：等长替换逐字符 `set character k of object text`（保留混排样式）；表格 `set value of cell "B2"`。
- 回撤图（第27期 P4 左，原生图在其后的隐藏页）：先查盘中最低价是否创新低，创新低要同时改回撤数、低点标注和红点；数据延长后横轴压缩，**红点、绿色回调色块、每个「最大回撤」气泡的尖都要重新对准**，导出后逐个放大检查。
- 私募策略净值不在工具箱：找私募服务同事要（对方在飞书单聊发「产品净值变更历史记录_*.xls」，`lark-cli im +chat-messages-list --download-resources` 可取）。**有分红用「复权净值」**；指数增强两只（中证500、中证1000）的走势图用户直接给运营周报截图。

## 四、截图页与私募模糊图
- 小程序截图（「今天几星」历史星级——要「全部」区间、估值表、首页）没有数据可换，请用户给新截图。叠在截图上的文字（如牛熊市标注）按新旧图网格线和首末日期线性映射重排；整页图放大时标注中心点、字号同比例放大。
- 图片页（隐藏页原生图导出成图片贴在可见页）：隐藏源页**紧跟在对应可见页后面**并设跳过；换数后导出（先临时 `skipped false`）、按原裁剪范围截图，删旧图、原位置原尺寸插新图，框直接画进 PNG（#FEAD00，线宽 = 6 ÷ 显示缩放）。
- **主动优选私募策略走势**（第27期第19页）：没有原生图，`modes/高净值/scripts/p19.py` 用复权净值和沪深300画「策略/沪深300/超额」并模糊，图例和首尾日期保持清晰，下期换数据重跑。
- **指数增强 500/1000 走势**（第27期第22页）：运营周报截图，裁掉底部「成立以来跑赢业绩基准 xx%」条，**整图模糊（图例里有产品名，一起糊掉）**，只把首尾日期按像素贴回清晰（`modes/高净值/scripts/zz_blur.py 截图 输出.png`）；左右两张各 868×540，标题「某私募中证500/1000指数增强策略」。

## 五、本机（汤爱学 Mac）Keynote 操作说明
- Keynote 是 `Keynote Creator Studio.app`（沙盒版）。**AppleScript `open POSIX file` 打不开文件**：先 `xattr -c`，用 shell `open -a "/Applications/Keynote Creator Studio.app" 文件.key` 打开，再 `first document whose name is "文件.key"` 拿引用；`copy_slides.py` 运行前也先把 src/dst 都 `open -a` 打开。卡住先查对话框（System Events 读 static text）。
- 同一个 .key 的副本文档 ID 相同，**不能同时打开**。要从旧版/定稿拷页时：解包副本，把 `Metadata/DocumentIdentifier` 换成新 `uuidgen`（不带换行），再 `zip -0` 回 .key，就能和正在用的文件同时开（第27期恢复误删页实测）。
- 主 skill 脚本的 sys.path 已改为按脚本所在目录查找（2026-11-26），不用再加 PYTHONPATH。
- 本机没有「图片素材库 library.db」：核对页码直接用来源期 PDF（PDF 页码 = 跳过页以外的第 N 张）。
- **改对象先列清单**：`shape k` / `text item k` 序号增删后会错位（第27期曾把页标题当小形状放大、删掉）。先列 `iWork items`（序号、类别、位置、尺寸、文字），按 `iWork item N` 操作并先校验；每删一次重新列。AppleScript 变量名不分大小写（`P` 和 `p` 是同一个），别撞名。
- 批注在 `iWork items` 里显示成 450×263 的 shape（文字=批注内容），不要删、不要移，出界检查时排除。
- **新插入的图在最上层**，会盖住气泡、文字：`modes/高净值/scripts/sendback.js X Y` 点一下图上空白处再「排列 → 移到最后面」。文本框不能 duplicate；幻灯片可以 `duplicate slide i of d to after slide j of d`。
- 只能走界面的操作：原生图表加横向刻度线（选中图表 → 坐标轴 → 值(Y) → 主网格线；弹出菜单打开后用纯 CGEvent `rawclick.js` 点选项，不要再发 AppleEvent）；图片/外框统一样式用「格式 → 拷贝样式/粘贴样式」从标准页复制（`menu.js 格式 拷贝样式`），**粘贴后检查阴影**，图片要设「无阴影」。
- 界面坐标：Keynote 窗口可能在副屏（x 为负），`screencapture -x a.png b.png` 截两块屏再标定；界面操作前请用户离开电脑。
- 读同事批注：AppleScript 读不到。解压 `Index.zip`（iCloud 共享后 .key 是文件夹包）里 `Slide-*.iwa`，用 `keynote_iwa/iwa.py read_iwa` 解出文本，和上一版比对新增中文串即批注；作者在 `AnnotationAuthorStorage.iwa`。

## 六、交付（高净值版）
1. AI 初稿 → 用户改（多轮小步）→ 用户上传 iCloud 共享文档，**之后共享文档是唯一正式版本**，每次动它前先备份到 `tmp/`。
2. 范丽丽在共享文档里批注 → 读出批注，列修改方案给用户确认后再改。
3. 提交钉大（王磊）→ 按反馈改。**钉大/用户说的页码 = 他们看的那一版的可见页码**；动手前先导出当前版本、按页标题核对——共享文档可能已被别人改过（第27期定稿后被误删 3 页，按标题比对才发现）。
4. 定稿后：
   - 写数据复核文档（第二节）。
   - 归档坚果云 `42 每月初高净值直播/YYYYMMDD 标题/`（日期=直播日），照第26期命名：`第NN期高净值直播_标题.key` + 同名 `.pdf` + 同名文件夹（`export … as slide images`，JPEG，`.001.jpeg`…，不含跳过页）。
   - **共享后的 .key 是文件夹包**（Data/、Index.zip、Metadata/），归档前转回单文件：解开 Index.zip 成 Index/，与 Data、Metadata、preview*.jpg 一起 `zip -q -r -0` 成 .key，`keynote_tool.py verify` 确认无缺图。之后再改就同名覆盖（cp -f），不要先删。
