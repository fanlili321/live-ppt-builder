> claude 2026-07-30 整理。取代旧《PPT规范手册V3》里"以PPTX为终点"的流水线部分；**视觉/配色/字体规范仍沿用**（来自品牌模版主题色 + 素材库）。最终交付 = `.key`（Keynote）。

## 0. 一句话总纲
最终成品是 **Keynote `.key`**。文字/复用页/表格/封面用 **Keynote 原生**做；**走势图/柱状图用 python-pptx 做出带样式的原生图表 → 转成 .key**（这是唯一能同时满足"原生可编辑 + 品牌配色"的路子）。

## 1. 技术流水线（实测可行，2026-07-30 验证）

### 1.1 底子与封面
- 工作文件 = **复制品牌模版** `图/直播ppt/2025.8【指数系列ppt模版】.key`（指数主题）或 iCloud 原件 `2025.12【投顾直播ppt模版】.key`（投顾主题，见 `rules/设计组件库_投顾模板.md`）为副本，**文件名带 `claude输出`**。
- **封面**：模版自带 slide1 就是品牌封面（橙标题+装饰图+徽章+页码点），**只改标题文字**，不重画。
- **内容页母版**：用模版里的 **「这个为准」内容母版**（`set base slide of slide N to master slide "这个为准"`），得到橙条页眉+银行螺丝钉徽章+页脚页码。别用封面母版（会把装饰图带到内容页）。

### 1.2 文字（Keynote原生，可设样式）
- AppleScript **能设** `object text` 的 `font / size / color`。
- 字体 = **思源黑体 `SourceHanSansCN`**（标题 `-Bold`，正文 `-Regular/-Normal`，星级/图内标注常 `-Medium`）。
- **字号（2026-07-30 从 2025.8指数系列 + 2025.12投顾 两模板逐元素实测，非估计）**：

| 角色 | 字号 | 字重/颜色 |
|---|---|---|
| 封面主标题 | **110**（长则缩） | Bold · 品牌橙 |
| **页标题** | **90**（长标题缩到 77–80 保持一行） | Bold · 黑 `#000` |
| 副标题/小标题 | **50**（投顾45–50） | Bold · 黑 |
| 正文 | **40–45** | Regular/Normal · 黑 |
| 图内标注/星级标签/数字 | **32** | Bold/Medium |
| 图片占位说明(￼) | 36 | Normal · 灰 `#767676` |
| **数据来源** | **30** | Regular · 灰 `#4C4C4C` |

> ⚠️ 之前用 72 号标题是错的，应 **90**（长标题才缩到 77–80，始终**一行不换行**）。

### 1.3 走势图 / 柱状图（关键：走 pptx→key）
- ❌ **不要**用 Keynote 的 `add chart`（AppleScript）：它能建图但**改不了颜色/图例/坐标轴**（图表对象只有 position/size/locked 属性，实测3次确认）。
- ✅ **正确做法**：用 **python-pptx** 建原生图表并设好样式（线色/图例/线宽），存 `.pptx` → Keynote 打开 `.pptx`、`save ... in POSIX file "x.key"` 转 `.key`。**转过去图表仍是原生可编辑 CHART 对象、样式保留**（实测：橙线#F17640 + 灰线 + 图例在上，转key后 `count of charts=1`）。
- python-pptx 设色示例：`serie.format.line.color.rgb=RGBColor(0xF1,0x76,0x40)`；`chart.legend.position=XL_LEGEND_POSITION.TOP`。

### 1.4 表格
- 简单表：Keynote 原生 `make new table`，cell 值可设；**底色/列宽/表头橙底 AppleScript 支持有限**（列宽可试 `set width of column`，cell 填色多半设不了）→ 需要精致表头就同样走 python-pptx→key。

### 1.5 复用历史页
- 大纲标注"某期第X页" → 下载对应历史成品 jpeg，**整页贴入**（Keynote `make new image` 满页 1920×1080）。
- 标注"数据待更新"的图表页 → 不贴旧图，按 1.3 用最新数据重做原生图。

## 2. 视觉规范（沿用品牌模版主题色 + 素材库，仍有效）

### 2.1 配色（精确）
| 用途 | 色值 |
|---|---|
| 品牌主橙 | `#F17640`（封面/表头/▶箭头/走势图主线） |
| 主蓝 | `#4874CB`（次要数据线/蓝气泡） |
| 走势图线①橙 | `#F17640` 主线 |
| 走势图线②蓝 | `#5B8FD6`（或双线第二条用灰 `#929292`，见规范E5⑦） |
| 走势图线③灰 | `#9A9A9A` 对照/基准线 |
| 走势图线④红 | `#E54C5E` |
| 黄色外框 | `#F2BA02` / `#FFBF00`，**无阴影** |
| 网格横线 | `#E0E0E0` |
| 表头 | 橙底 `#E97C2D` 白字；偶数行 `#F5F5F5` |
| 数据来源灰 | `#999999`（页内小字）/ `#4C4C4C`（模版来源行） |
| 估值三色 | 低估绿 `#06AC67`·正常橙 `#FF9343`·高估红 `#FF5544` |

### 2.2 走势图硬性细则（规范E5/E7，仍适用）
1. **原生可编辑**（用 pptx→key 实现），不用图片/截图。
2. **图例在图表上方**。
3. 去掉左竖轴、底横轴线，**只留浅灰横向网格**。
4. **高低点红圆点** `#FF2700` 精确落在线上，旁标日期+收盘价。
5. 黄色外框**无阴影/倒影**。
6. 线宽 ≈2.5–4pt；主线橙，第二条（全收益/对照）灰或蓝。
7. X轴只显示首尾日期并加粗（长区间稀疏标签）；来源右下角灰字。
8. 图框比例≈16:9，黄框内缩进留白，图例独占顶部不压曲线。

### 2.3 页框（内容页）
- 左上3个浏览器圆点（默认左2空心橙环+右1实心橙）；右上搜索药丸"🔍银行螺丝钉"；顶部橙→浅黄渐变细条；淡网格底纹。**这些用模版「这个为准」母版自带，不用自己画。**

## 3. 安全规矩（2026-07-29 误删事故后铁律）
1. **绝不用 `front document`**；一律 `set d to (open POSIX file …)` 或按**完整文件路径/唯一文件名**锁定我的文件；找不到就中止，**绝不退回操作别的文档**。
2. 动手前先列出 Keynote 已打开的文档；**用户打开着的文件绝不碰**；在**隔离副本**上做。
3. 我输出的文件名一律带 **`claude输出`**，和人工/别的AI的稿区分（别混）。
4. **不写盲批量 delete slide**；删除前核验页数，不符即中止。
5. Keynote 自动化前先 `open -a` 启动；osascript 用 `with timeout of 600 seconds` 包住。

---

## 4. Keynote 自动化能力边界（实测）
| 能做 | 不能做（AppleScript） |
|---|---|
| 文字 font/size/color | 图表线颜色/图例/坐标轴（图表只有 position/size/locked）|
| 建原生图表+填数据 | 改**已存在**图表的数据（-10006）|
| 表格 cell 值、部分列宽 | 表格 cell 填色/表头橙底（多半不行）|
| 满页贴图、母版切换、跨页删/移 | —（图表样式 → 一律走 python-pptx→key）|

## 5. 标准流程（465类复盘/估值类直播）
1. 读飞书大纲（V2为准），逐页定：页型/标题(H3原文)/正文/图表口径/数据需求/复用来源。
2. 出AI解析稿发飞书确认。
3. 取数（Wind：指数/基金全收益代码见记忆；投顾组合净值走 https://dbms.yhlsd.com/ ）。
4. 复制品牌模版→工作文件(claude输出命名)；封面改标题；内容页套「这个为准」母版。
5. 文字/复用页/表格用Keynote原生做；**走势图用python-pptx做styled原生图→转.key合并**。
6. 导PDF逐页自检（数据/配色/字体/版式/无叠字溢出/来源）。
7. 交付 `.key`（留PDF验稿）。发内容小分队群按流程@。
