## 二、固定版式组件（每页通用）

### 页眉（内容页）
- 左上：3 个"浏览器圆点"（直径≈0.5cm），默认左2空心橙环 + 右1实心橙 `#F17640`；**封面/首节**首点可实心。
- 右上：圆角"搜索药丸"框（白底、橙描边、圆角全径），内含 🔍 + 「银行螺丝钉」。
- 顶部：橙→浅黄 横向渐变细条（贴顶，约页宽 70%~满宽）。
- 全页：极淡网格底纹 `#EAEAEA`。

### 页脚
- 左下：`©版权所有银行螺丝钉，侵权必究`（灰 `#999`，小字）。
- 右下：页码（灰，小字）。

### 封面页
- 右侧：竖向大圆角橙弧块（`#F17640`）叠半透明金融图（柱状/K线/笔）。
- 左侧：大标题（橙 `#F17640`、Bold、左对齐、自适应 40–60pt、按标点断行）。
- 标题下：橙色细分隔线渐隐；下方搜索药丸「银行螺丝钉」。
- 左下：3 个页码圆点（实心橙 + 2 空心橙环）。

### 过渡页（章节页）
- 顶部橙色块 `#F17640` + 下压一个大白色圆角卡（带浅阴影）。
- 卡内：大号「02」橙色 + 黑色章节标题（可两行）；右上角小版权字。
- 左下：3 个页码圆点。

## 三、内容组件库（可复用，优先原生重建）

| 组件 | 样式规格 |
|---|---|
| **箭头要点** | 橙 ▶（`#F17640`）或 橙 ◉ 环形符 + 黑色 Bold 文案；行距宽松 |
| **气泡(callout)** | 圆角矩形 + 尖角指针。两种：①实心橙底白字（强调结论）②浅橙底`#FCE6D2`+橙描边、深色字（补充说明）；蓝气泡`#7FA8DA`白字（风险/对照） |
| **对比盒(box)** | 大圆角矩形，浅橙/浅蓝/浅灰三色底；标题 Bold 居中 + 说明文字；常 2–3 个并排 + 底部气泡 |
| **思维导图/树状** | 左根节点=实心橙圆角块白字；中间层=浅橙圆角块 `#FCE6D2`；叶子=白底+橙描边圆角框；连接线=黑色折线（直角） |
| **原生表格** | 表头橙底 `#F17640` 白字 Bold；首列加宽+灰底 Bold；数据行斑马纹（灰`#EFEFEF`/米`#FDF6EE`）；字号≈16；单元格不溢出、固定行高 |
| **走势图** | 见色板②；橙线主、灰/蓝对照；黄框、左侧手动图例、红圆点高低、整数刻度、共同交易日对齐、右下"数据来源：Wind" |
| **双Y轴/叠加图** | 两个原生图叠放；底层面积浅蓝 `#DCE7F8`/`#C7DBF0`（Y2在右）、顶层折线橙（Y1在左）；两层 crossBetween=midCat 对齐 |
| **柱状图** | 主橙柱 `#F17640`；强调柱用蓝 `#7FA8DA`/红框；对照柱灰 `#9A9A9A`；柱顶数据标签 Bold；黄框 |
| **条形对比图** | 左右对称双向条（如最大回撤蓝 vs 年化收益橙），数值标签贴条端 |
| **饼/环图** | 股票=橙 `#F17640`、债券=蓝 `#7FA8DA`；中心可留环标注（如"40岁为例"）；引导线+标签 |
| **微笑曲线** | 浅蓝面积底(指数)；橙色平滑弧线(微笑)；绿/粉高亮区段；大号粉红上扬箭头；阶段文字标注 |
| **升降箭头** | 红↑（利率/上涨）、蓝↓（价格/下跌）；3D 灰色大箭头用于流程指向 |
| **估值三色标签** | 见色板4，绿/橙/红圆角块白字，竖排对齐估值表三段 |
| **页码圆点** | 3 点，1 实心橙 + 2 空心橙环，直径≈0.45cm，间距≈0.6cm |
