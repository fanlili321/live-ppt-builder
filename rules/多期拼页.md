# 多期拼页（大纲引用好几期的页面）

几乎每期大纲都引用好几期的历史页。做法：**把每一期被引用的 `.key` 都下载下来，把对应页面整页复制粘贴进底稿**，再换数据、改文字。整页复制能保住原生图表、母版、字体和配图，比重画或贴图稳。

## 步骤
1. **列出引用清单**：从施工单里汇总「期数 → 页码」。引用页最多的那一期做底稿，其余都是「来源期」。
1.5 **先查本机历史素材库（秒级，不用下载）**：`/Users/fanlili/Desktop/范丽丽./图片素材库/library.db`（只读打开，SQLite），表 `inbox_items` 里每页一行：`episode_label`（如「公募直播第455期」）、`deck_title`、`page_number`、`page_count`、`ocr_text`、`relative_path`（页图）。用它核对大纲写的「第NNN期第X页」是不是那一页（看页图/OCR），并确定每期要哪几页：
   ```bash
   sqlite3 -readonly "/Users/fanlili/Desktop/范丽丽./图片素材库/library.db" \
     "select page_number, deck_title, relative_path from inbox_items where source_group='ppt_jpegs' and episode_label='公募直播第455期' order by page_number"
   ```
   私募直播 `source_group='private_jpegs'`，对外演讲 `speech_jpegs`。素材库只有页图、没有 .key；**每周一更新上一周的 PPT**，所以上一期不在库里是正常的——上一期页面直接看它的定稿 .key/PDF（2026-11-10 时公募到 484 期，且 ep484 文件夹里混进了 485 期那份「黄金大幅波动」——同一期多个 deck_title 时按标题区分）。
2. **下载**：只下载**被引用那几期**的 `.key`（不整库下载），先看本机缓存 `~/Projects/银行螺丝钉直播/history_keys/NNN期_标题.key` 有没有，没有再从历史成品库下载（`lark-drive`）并存进缓存，下次直接用。用时 `cp -R` 到 `output/NNN_claude输出/src/` 再操作，缓存里的不动。
3. **核对页码**：大纲写的「第X页」以该期**定稿**为准；先导出来源期页图或读页标题，确认第 X 页确实是大纲描述的那页（页序改过的期次常差一两页）。对不上就问用户。
4. **整页复制**：用 `scripts/copy_slides.py`（Keynote 界面里的「拷贝幻灯片 → 粘贴到底稿指定位置」）：
   ```bash
   python3 scripts/copy_slides.py --src output/NNN_claude输出/src/455期.key --pages 10,12 \
       --dst output/NNN_claude输出/NNN期_主题_v1_claude输出.key --after 5
   ```
   - 一次一个来源期；脚本每页自动核对底稿页数 +1、新页标题、图表数，不一致立即停止且不保存。
   - 原理：来源副本里先把第 p 页挪到第 1 页 → 点第 1 张缩略图 → 编辑▸拷贝 → 挪回；底稿点第 1 张 → 粘贴 → 挪到目标位置。不用方向键（实测会丢键/页码回报滞后）。
   - 粘贴进来的页可能带来源期的母版（Keynote 会把母版一起带进来）。检查页框/页眉和底稿一致；不一致就 `set base slide` 换成底稿母版。
5. **换数据、改文字**：同 SKILL.md Step 5（`keynote_tool.py` 按页标题定位新粘贴的页）。
6. **核验**：`keynote_tool.py verify` 看缺图；导出页图逐页看；字体字号按样式规范检查（老期次的字号可能不一样，按 485 规范统一）。

## 前提：辅助功能权限（一次性，用户本人开）
AppleScript 不能跨文档复制幻灯片（`duplicate slide` 到另一份文档实测不生效），只能走 Keynote 界面的拷贝/粘贴，需要用「系统事件」模拟操作。这要求运行脚本的 App 有**辅助功能**权限：
- 系统设置 → 隐私与安全性 → 辅助功能 → 打开**小写的「claude」**（灰白图标，是 Claude Code 命令行程序，osascript 算在它头上）；只开橙色图标的 Claude App 不够（2026-11-10 实测）。开完可能要重启 Claude App 才生效。
- 这是系统安全设置，**由用户自己开，AI 不代改**。没开时脚本会报 `osascript 不允许辅助访问 (-1728)`。
- **2026-11-10 已授权并实测通过**：484 副本 5 页（思维导图页、双图表页、图表+表格页、总结页）→ 485 副本，标题/图表数/位置全部核对一致，`verify` 无缺图，导出页图与原页一致。
- 运行时 Keynote 会切到前台、鼠标会动一下，**期间不要操作电脑**（每页约 15 秒）。

## 退路（权限没开或复制失败时）
- 走势图页：底稿里复制同类页 → `keynote_tool.py set` 换成该页数据（样式跟底稿一致）。
- 纯文字/表格页：底稿复制同类页改文字。
- 示意图/截图页：导出来源期该页图片，整页贴图（只读，不能改）。
- 用了退路的页在过程记录里标出来。
