## 5. 用户定的统一规则（2026-11-12，486 期）
### 5.1 图片默认加边框
- 规格：**边框 → 线条 → 实线，颜色取 Keynote 色板第 3 行第 4 格橙黄（文件内存值 RGB 0.995/0.681/0 ≈ #FEAD00），6 点，无阴影**。截图、二维码、App 页、估值表、星级图等所有图片都加。
- 复用历史页时，凡是图片边框和这个不一致（没有边框、黄色 #F8BA00、带阴影、烤在图片里的边），都改成标准边框。
- 做法：`python3 scripts/set_image_borders.py 输入.key 输出.key`（把所有图片的样式引用换成文档里的标准边框样式，同步 Metadata）→ `keynote_tool.py verify` → 打开导出目检。文档里还没有标准样式时，先在 Keynote 里手动给一张图设好再跑。
- 图片像素里自带的边（如大纲给的二维码自带约 18px 黄边 #F1B13F）要先裁掉，再用原生边框；**不要再往图片里烤边框**。
- **外框同一规格**（2026-11-12 补充，P18 被指出）：走势图外框、内容卡片框等所有外框的线条也是 #FEAD00、6 点、实线（391 等老期次是 #FFC000、3 点，要改）。阴影状态保持原样（用户改 P6–P8 时只换了颜色和粗细，保留了阴影）。浅橙气泡的 1 点细描边不是外框，不改。
- 做法：`python3 scripts/set_frame_strokes.py 输入.key 输出.key`（改外框所用样式的描边颜色/粗细，共用样式一次改全；宽≥400、高≥100、线≥2pt 才算外框）。新画的走势图页（python-pptx）转 .key 后也要跑一遍。
### 5.2 正文要点前加 ▶ 三角——按意群加，不是每句都加（2026-11-12 用户明确）
- **先按意思分段，再加三角**：前后几句说的是同一件事（同一个观点的展开、因果/转折的前后句、补充说明），算一个意群，**只在这一组的第一句前加一个三角**，后面几句缩进对齐、不加三角。意思换了（另一个观点、另一个层次）才另起一个三角。
- 判断方法：把几句话连起来读，能当成一个自然段讲完的，就是一个意群；去掉中间换行意思不变的，就不该各加一个三角。
- 例（486 期）：
  - P15「一战结束之后，美股迎来了一波大幅上涨。」+「不过1929年遇到了经济危机……长达十几年的熊市。」→ 同一段经过（先涨后跌），**1 个三角**（当前做成了 2 个，不对）。
  - P8「少部分优秀基金经理……长期跑赢指数。」+「这些基金，也是我们的主要投资对象。」是一组；「参考美股，主动基金并没有消失。」+「也涌现出类似富达……的基金公司。」是另一组 → **2 个三角**（当前做成了 4 个，不对）。
  - P3「可以参考螺丝钉全球指数星级……」和「目前在3点几星……再提高比例。」是两个不同观点（方法 / 当前建议）→ 2 个三角，对。
  - 总结页每条是一个独立结论 → 每条一个三角，对。
- 样式：三角 44×39 品牌橙；x = 文字框 x − 62（文字框右移 62、宽度减 62）；三角**中心比该意群首行文字中心高 8px**（形状 y ≈ 首行中心 − 29.5）。一个意群放在同一个文字框里，组内句子之间用段内换行，组与组之间留段间距。
- 不加：页标题、小标题（（1）（2）…）、图上日期/标注、数据来源、气泡里的字、表格、二维码步骤说明、本身已是项目符号（•）的列表。
- 做法：AppleScript 不能复制形状，用 `scripts/gui_paste_shape.js` 从总结页拷三角、粘到各页，再用 AppleScript 定位；右移后检查折行（折行会把文字顶到下面的图框上，需加宽或减字号）。
### 5.3 走势图框白底
- 走势图黄框和图表区要**白色填充**，挡住母版的方格底纹（不然图后面透出方格线）。python-pptx 新画的图：框 `fill.solid()` 白色，chartSpace / plotArea 的 spPr 设白色实心填充。复制历史页的图一般已是白底，新画的必须检查。

## 6. 486 期汤爱学复核反馈（2026-11-12）
### 6.1 走势图纵轴：贴合数据、整数刻度、必须有 0 刻度线（参考 486 期 P20）
- 多条线挤在中间、上下大片留白时，要收紧纵轴范围，让波动看得出来（标题讲「波动较大」，图就要把波动拉开）。上下各留约半格空白，不为某一条极端线放大整张图。
- **刻度必须是整数步长，并且包含 0 刻度线**（收益率、累计涨跌幅图尤其要有 0 线，一眼看出涨跌）。参考 P20：-200%、0%、200%……800%。
- 范围取步长的整数倍、且 0 在范围内：数据 -15%~41% → -20%~60%（步长 20%，刻度 -20/0/20/40/60）。python-pptx 画的图转进 Keynote 后纵轴分 4 段，只认 minimum/maximum、不认 major_unit，所以 (max-min)/4 要是整数步长，并且 min ≤ 0 ≤ max、0 落在刻度上。用户手调成 -20%~50% 会出现 -3%、15%、32% 这种刻度，要避免。
### 6.2 图上所有文字的最小字号（486 期汤爱学、用户反馈）
- **坐标轴刻度文字、图例、图下表格（表头、数值、日期）一律不小于 30 号**，与首尾日期、数据来源同级，保证手机上看得清。参考 P20 纵轴刻度约 30 号。
- 放不下时先精简文字（如「最大回撤出现时间」→「出现时间」、名称去掉重复后缀），不要靠缩字号。python-pptx：`legend.font.size`、`value_axis.tick_labels.font.size`、表格 run 字号都设 30。
### 6.3 最大回撤标注圈
- 圈只框住回撤段（峰值→谷底），不要把前后上涨段一起框进去。换数后横轴压缩，圈要跟着重新缩小、对位。
