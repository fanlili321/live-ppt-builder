# 样式规范（485 期定稿实测，2026-11-10）——以本文件为准

来源：485 期定稿（`黄金大幅波动，当前投资机会如何？.key`）逐页实测：文字用 AppleScript 读 `font/size/color of character 1 of object text`；框线、色块、三角用 Keynote 导出 1920×1080 PNG 逐像素量。与 `spec/制作规范_Keynote版V1.md`、`素材库/设计素材库.md`、`feedback_ppt453_chart_rules.md` 冲突时，**以本文件为准**（那几份里的「正文≤25pt」「标题40pt」是旧 pptx 1x 尺寸，不适用 Keynote 1920×1080）。

> **做新元素的首选方法**：从底稿里复制同类元素（或用 Keynote「拷贝样式 / 粘贴样式」），不要手填数值——颜色在 Keynote 里存的是色彩空间值，导出图片测得的十六进制会略有偏差，复制最稳。下表数值用于核对。

## 3. 版式位置（1920×1080）
- 页标题文本框：x=133, y=114, 1654×180（两行标题 1654×250）。
- 走势图黄框：约 x=151–177, y=260–360, 宽 1611，高 575–622；图表在框内。
- 首尾日期：图框内左下 / 右下，176×41。
- 数据来源：右下（约 x=1407–1431, y=869–940），341×41。
- 页码：x=1833, y=1008。
- 页框（左上三圆点、右上「银行螺丝钉」搜索框、顶部渐变条、网格底纹）来自母版，不要自己画。

## 4. 核对时常见问题（485 定稿实测发现）
- 个别文本框混入非思源字体（P6 一段 HelveticaNeue-Bold 36）——新增/粘贴文字后检查字体。
- 空文本框（Times-Roman 12，无内容）可忽略，但不要新增。
- 批注类文字（HelveticaNeue 12）定稿前删除。
