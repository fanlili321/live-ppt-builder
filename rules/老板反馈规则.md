# 老板/领导反馈规则（制作端）

**完整的成品检查清单在 `ppt-review` 技能**（`.agents/skills/ppt-review/references/历史问题库.md`，王磊、汤爱学历次反馈整理，260 行，含数据四点双源、对象身份、走势方向、区间同步、跨页勾稽、颜色一致性、图片清晰度、命名、合规、星级来源等）。**不在这里重复**——制作时就按那份清单做，交付前再走 `ppt-review` 复核。

本文件记两类东西：① 2026-11-10 读 226课程群 2026-05~11 王磊 160 余条反馈后补进 `ppt-review` 的条目（对照用）；② 从成品看不出来、属于制作端做法的规则。王磊的反馈为准，汤爱学辅助。

## 一、2026-11-10 已补进 ppt-review 的条目（数据第27条、图表第15条、版式第11条、文字第9–10条，这里留作对照）
1. **小数位统一两位**，末位 0 不省（-10.2% → -10.20%）（王磊 2026-08-05，文章等物料同样适用）。
2. **不放无用装饰元素**：图标、装饰图、人像不要喧宾夺主；名言页用书籍推荐语格式，不刻意放大人名（2026-06-15、10-16）。
3. **截止日统一规则**：线下活动走势图统一到活动前一个周五收盘；组合数据拿不到更新的，统一到上周五；带明确起止日的回测图不动（2026-08-27）。
4. **复用页的线条颜色、样式不能被改动**（汤爱学 2026-06-24，曾出现复用后颜色/图例标反）。
5. 措辞：策略指数不称「窄基」（2026-08-11）。

## 二、制作端提前避免（从成品看不出来、属于做法的）
1. **每次发 PPT 同步附每页数据核对情况**（王磊 2026-09-18）：= 环节 1 过程记录里的四点核对表（`rules/复核记录与交付.md`）。
2. 王磊给了大纲的页面，不能只把文字可视化，要**补数据、图表、走势作为证据**（2026-08-31）。
3. 站在用户视角：预想客户疑问并在页面里解答（2026-11-05，如盈利波动大要给原因）。
4. 不重新发明轮子：同一张图、同一套框架优先用书籍和往期定稿的同一版本（2026-07-06、07-14）。
5. 频繁变化的数据每次都重新取：ETF 资金流入、组合走势、星级颜色档位，差一天都会不同（2026-10-27、07-21）。
6. 和已上线内容（文章、往期 PPT、牛熊信号板）口径冲突时，以已上线为准，拿不准问用户（2026-10-13）。
7. 一页字少、字大：PPT 在小鹅通手机端约占屏幕 1/3，内容多就拆页；字号按 `样式规范_485定稿实测.md`（2026-06-15）。
