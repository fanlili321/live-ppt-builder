银行螺丝钉直播 PPT 制作规则（2026-06 用户多轮批注归纳的最终版，做PPT必遵守）。配合 [[reference-feishu-cli]] 读大纲。实现见 `/code/`：**参数化管线** ppt_engine.py(引擎) + make_deck.py(入口) + spec_xxx.json(每期内容)；技能 SKILL.md(live-ppt-builder)。

**标准流程必须含"解析确认"步**：用户发的飞书大纲是真人看的；先解析成「AI解析稿」=理解确认+Wind取数计划。内容：直播标题；逐页(①标题②内容③图表样式④是否提数据需求⑤数据需求=指数代码+时间段+**周频/日频**+字段(收盘价/区间高低/天数/涨跌幅)+标不标红点)；不上PPT的内容；待确认清单。**发用户确认、改完后才生成 spec.json、才调Wind拉数、才出PPT**（拉数在确认之后，绝不先斩后奏）。
**频率默认规则（用户449确认）：走势图区间三年以内按日(D)、三年以上按周(W)**，特殊情况大纲另注明。
freq 已支持：fetch_kline(code,start,end,freq='D'/'W')，周频=日频按ISO周取每周最后交易日；spec 的 chart/chart_dual 用 "freq":"W" 启用。

**解析必须严谨（用户449测试纠正）：**
1. **标题=大纲 H3 原文，只此一句**（序号后那行 H3 字号的才是标题）。**(1)(2)(3) 等副点、展示/数据需求/样式说明，统统是正文内容，绝不能拼进标题**。**多页标题相同是正常的，照 H3 原样重复即可，不要造副标题、不要把(n)塞进标题**；自己内部用页码(P13/P14…)区分就行。不要自己改写标题。用 blocks 的 children 树取 H3 原文，不要用扁平 raw_content 猜。
2. **图表类型必须逐页看参考图(image.png)确定**，不能按正文"走势图"措辞猜。实际可能是：双Y轴、线+面积图、打点(加息降息带%)、升降箭头、多线(4-5条)、走势图+左侧表格、净利润柱+表格等。先 Read 每页参考图再定 type。
3. **数据需求严格按大纲原话**：出现"需要提数据需求"=是；"这个不用提数据需求"/"数据不用更新"=否；无图表的设计/文字页=否。别自己加。
4. 只解析 V2 大纲（"以此为准"），V1 全忽略。

**数据需求xlsx = 权威数据源（重要）**：用户会发当期「PPT数据需求」xlsx（如 `【第449期直播】数据需求…xlsx`），里面有**所有页的真实数据**——含外汇/利率、组合净值、各指数的确切代码和区间、6轮牛熊权威表。优先用 openpyxl 读它做内联 data（每个 sheet 对应一页，参考 build_449.py 的 series() 读法），不必都走 Wind。Wind 取不到/不确定的代码先从这个表里找。截图类(星级走势、信号板、估值表、止盈图)表里一般没有，用占位页等用户给图。

**https://dbms.yhlsd.com/ = 投顾组合净值数据源**（2026-08起替换旧的「螺丝钉数据工具箱」aiforce入口 `https://epndqwwg0a.aiforce.cloud/app/app_4kbcxg8fsedtu`，那个已停用）。**投顾组合净值是这里独有的内部数据**（指数增强C、全市场指数C+业绩基准、主动优选C 等19个组合，列：交易日期/组合名称/组合单位净值/基准单位净值）。取法：**真实登录浏览器访问**（飞书/豆包扫码登录，不是 `lark-cli apps` 命令——那个身份没有协作者权限）→登录后直连 REST API（如 `/api/portfolio-nav?portfolioName=...&beginDate=...&endDate=...&page=1&pageSize=2000`）→用 **Claude for Chrome 扩展**驱动浏览器，在页面 JS 里 `fetch(url, {credentials:'include'})` 复用已登录会话直接取数据，比等"历史导出"异步任务更快；取回JSON直接解析，不必再等导出Excel。指数/星级仍走Wind（`code/chart_gen.py`）。

## 字号 / 颜色 / 字体
- 封面标题：自适应 40–60pt、橙色 #E97C2D、左对齐；按标点断行避免孤字；**末行压母版横线≈7.8cm**。
- 内容页标题：**固定 40pt 黑色**居中（文字过多才降到36）。
- 正文/要点：**≤25pt**（默认20，总结22）；橙色箭头 ▶ 用主色 #E97C2D。
- 字体一律 **Source Han Sans CN Regular**，文字必须同时设 latin/ea/cs（否则中文回退）。图表也要设 chartSpace 默认字体含 ea。

## 作图方式（禁止截图）
- 大纲标注来源"某期某页"（如346期第5页）或"数据待更新"的页面，**自己抓 Wind 数据重做**，不能贴大纲参考图截图。
- 走势图、表格都用 **PPT 原生对象（可在PPT内编辑数据）**，不是图片。（早期用 matplotlib 出PNG 的做法已废弃。）

## 走势图（所有图通用，与 tool-ppt-chart 视觉一致）
- **所有图表都必须有"数据来源：Wind"**（右下角灰字#999），一张都不能漏。
- **所有Y轴刻度一律整数**（不保留小数）：点数用 `#,##0`、百分比用 `0"%"`（含双轴图的%右轴）。
- 线色橙 **#F17640**，线宽≈2.5pt；多线按配色板顺序：①#F17640 ②浅蓝#7CA7E0 ③灰#929292 ④中蓝#6674A6 ⑤红#FF2700 ⑥玫红#C24785 ⑦金黄#C8A028（全指+全收益=橙+浅蓝）。
- **多线/双线必须按共同交易日(交集)对齐**：不同指数交易日可能不一致，取所有线都有数据的日期做X轴，每条线每点都有值，**绝不能断线/断断续续**。
- 黄色外框 **#FFBF00**≈2.5pt，**无阴影/倒影**。
- 坐标轴**无多余轴线**（去左竖线、底横线），只留浅灰横网格 #E0E0E0。
- 图表文字≈18pt、思源黑体。
- **图例靠左**：关掉原生图例（原生只能居中），**手动画**橙短线swatch+系列名，左缘对齐曲线左侧（绘图区左缘，在Y轴数字右边）；swatch 与文字**垂直居中**。
- **Y轴自适应**：漂亮整数刻度，范围恰好包住数据最大/最小值（用整数步长，如 3684/6687→3000~7000 step1000；别出现 3300/5300 丑刻度）。
- **高低点**：红圆点用原生 marker series（仅高低点有值其余None，CIRCLE，#FF2700）精确落在曲线上；`style_chart_xml` 勿统一清标记点。标签**不用原生数据标签**（会截断+黑引导线），改自己画文字框，按固定绘图区几何(PLOT_X/Y/W/H)+Y轴min/max 算出点cm坐标放在点旁；边缘避让（左点向右展开/右点向左/中间居中，高点上方/低点下方），不压轴/线/彼此。
- **占满宽度**别留大片侧白；不强行固定比例但避免太扁，宽:高上限≈2.5；高度随页面文字自适应。
- **留白对称**：X轴日期紧贴曲线下方；日期↔黄框底 = 图例↔黄框顶（≈0.35cm，FRAME_MARGIN）；绘图区PLOT_H拉满让曲线底贴近X轴；两侧≈0.7cm。

## 双Y轴/叠加图（标准做法：两个原生图表叠放，用户点拨后定型）
- **双Y轴图 = 两个图的叠加**（用户原话）。不要用单对象组合图XML（试过两次都歪）。标准实现 `add_overlay_dual_axis`（ppt_engine.py）：
  - **底层**：面积图(或柱状图, bottom_kind='bar')，自己的 Y2 → `tickLblPos='high'` 把刻度放**右侧**，0起整数%；
  - **顶层**：折线图+标记点，自己的 Y1 → 左侧整数；`_make_transparent`(chartSpace+plotArea noFill) 露出底层；`_remove_gridlines` 网格只留底层；
  - **对齐三要素**：①两图同位置同尺寸 ②同一绘图区 manualLayout(PLOT_X/Y/W/H) ③**两层都设 `crossBetween='midCat'`**（否则折线在格子中间、面积撑满格子，左右差半格不对齐）；
  - 黄框/手动图例/起止日期/%标注/箭头/数据来源 作为叠加元素画在最上层；两张图都原生可编辑。
- 通用于：折线+面积、折线+柱状 等叠加图（以后会常用）。
- **叠加图底层面积/柱状的蓝色用低饱和浅蓝 `#C7DBF0`**（用户反馈 #9DBFE6 太鲜艳）。
- 加息/降息标记点：白底圆圈，加息红边#FF2700、降息绿边#2BA84A，打在折线上，%标注放点上方。
- p4_render.py(matplotlib版) 仅作备份，不再默认使用。

## 表格（原生表格，自适应不溢出）
- 第一列加宽让"第一轮"不换行(≈3.6cm)；列宽合计=内容宽(32cm)；单元格 word_wrap=False、固定行高(≈1.05cm)避免过高；字号18；表头橙底#E97C2D白字、偶数行#F5F5F5。

## 排版
- **文字多的页左右排版**：要点放左≈12.5cm、走势图放右（图更大）；文字少/无的页用上下排版。
- 通用：任何页面不得出现 文字叠文字/文字压图形/表格溢出，生成后要检查。

## 页面类型 / 模版 / 复用页文字
- **页面类型决定用哪个母版版式（三种）**：封面页→"标题幻灯片"版式；正文页→"自定义版式"；**过渡页/标题页**→母版里含"02"编号占位+"单击此处"文本框的版式（get_section_layout 自动找；'02'是title占位放编号，'单击此处'是普通文本框位置叠白底文本框放标题）。解析稿要标明每页类型。
- **只有标题、没有任何正文/图的页 → 用过渡页模版**（spec type `section`，可带 number）。
- **默认每个PPT的 P1 = 封面标题页**。
- **一页有多张参考图时，统一取第一张、忽略其余**（用户456确认的通用规则：第一张就是要放PPT的定稿）。
- **复用的设计页(如四圆/宽基树状/微笑曲线/对比表)优先做成原生可编辑**(用形状/表格重建,样子照大纲)，不要直接贴图；做不出再考虑贴图或向用户要 keynote 源文件。
- **纯图页(直接放图，如P2/P3/P4信息图)要把图放到最大**(用户456补充)：压缩标题与图间距、向下用满到贴近页脚(~18.3cm)、宽度可铺到整页(~33.4cm)，避免两侧/上下大片留白导致看不清。img_page 已加 `big=True`(默认)实现；有箭头要点的图页不强行铺满。
- **复用历史走势图的页，截图里内嵌的文字也要提取出来**放进解析稿和PPT（作为该页文案/要点）——不能只画图丢了文字。做法：Read 该参考图把文字转写出来。例：453的 第一轮熊市/第二轮牛市/第三轮牛市/第三轮熊市/第四轮牛市/第四轮熊市/第五轮牛市 的文案都在截图里，需读图补全。

## 排版与设计硬规则（2026-06 用户456批注归纳，A–L，必遵守）
设计元素/颜色一律以 [[reference-ppt-design-assets]] 设计素材库为准。
- **A 标题净化**：标题里的过程性/修订性措辞——「（根据反馈调整）」「（根据反馈新增）」「（根据建议新增）」「（新增）」等，**一律删除**，PPT 标题只留实质内容（这些是沟通过程信息，不进PPT）。
- **B 标题↔正文留白**：标题与下方正文/要点间留**统一留白**，不能贴在一起；各页该间距保持一致。
- **C 纯图页放最大**：信息图（P2/P3/P4等）放到最大，保证手机端看清、减少四周留白；同类页尺寸统一（见上条 img_page big=True，必要时再加大）。
- **D 数据来源**：仍放**右下角**灰字#999；**尽量一行**，若必须换行则**左对齐**。
- **E 数据标签防重叠**：标签会互相重叠时（柱多/数值挤，如P6上市公司数量），**直接不显示数据标签**。
- **F 形状/盒子样式+自适应**：盒子/气泡/圆圈的颜色样式从素材库取常用款（对比盒=浅橙底#FCE6D2+橙描边）；盒子大小**按文字多少自适应**，**禁止文字溢出**框外。
- **G 坚决避免内容贴边**：任何页内容不得贴页面边缘（左右尤其留足边距），除非内容确实很多；多个并排元素（如四圆）**间距均衡**，不能两侧贴边、中间空一大块。
- **H 设计元素统一参考素材库**：所有颜色、组件样式以 设计素材库.md 为准。
- **I 元素绝不相互遮挡（硬规则）**：标题/正文/图/表/形状之间**不得重叠遮挡**（树状压标题、表格顶到标题、圆圈压正文都不允许）；生成后必检查每页无遮挡。
- **J 充分利用版面、避免大片留白**：表格/文字/图按版面**重新匹配**，文字适当**放大**、行高撑满，**下方不留大片空白**；总结类文字页文字要够大、铺满。
- **K 表格自适应**：单元格内容较多时**换行**；行高/字号随内容和版面调整，不溢出、不顶标题。
- **L 复杂设计页照原版重做**：宽基树状等做不好就**照原版大纲(Keynote模板)重新设计**，不要凑合。
- **M 设计页必先Read原版参考图、1:1照搬（强制）**：做任何设计页(四圆/树状/微笑曲线/对比框/信息图等)前，**先 Read 该页原版参考图**(大纲 image / Keynote 模板对应页)，严格按它的**层级、形状、颜色、连接线走向、文字配色**复刻，禁止凭通用理解自由发挥。例：456 P9 宽基树状=金橙根圆(深字)+橙色扇形连线+右侧6浅橙无边叶子框(指数名橙粗体＋：含义深色)；P8 四圆对称简单结构通用画法即可重合。配色一律对照 [[reference-ppt-design-assets]]。
